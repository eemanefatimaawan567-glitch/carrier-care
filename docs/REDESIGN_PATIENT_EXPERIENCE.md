# Trust-first patient experience redesign

- Default `/` landing page is now a patient-centered, English/Arabic responsive website, with preserved DNA intro.
- Four-stage guided fictional workflow: scenario, separate opt-in permissions, plain language result, counseling guidance.
- Consent simulation is **not** a substitute for server-side authentication or real consent; old technical UI preserved at `/advanced.html`.
- The 100-square diagram appears ONLY for the two-carrier example when both consent; 25 highlighted squares reflect per-pregnancy autosomal recessive inheritance in that specified scenario.
- A pre/post comprehension question demonstrates a potential testing method, not real efficacy or health literacy validation.
- Access history is local browser activity, not server audit logging.
- No live UAE Pass, counselor booking, real-patient integration, diagnosis, or clinical validation claims.
- Published ACMG resource is linked and Asif Jamal's limited five-statement fact check is accurately attributed.
- Bilingual Arabic content is provided for core screens. Professional medical translation and user testing are still needed before actual clinical use.
- No patient data entry is requested or stored by the new guided screen.

## Run
Run the original project using README instructions and open `/` for patient experience, `/advanced.html` for previous technical interface. Static preview can be opened with `frontend/index.html`; backend-dependent advanced features require the original server.
