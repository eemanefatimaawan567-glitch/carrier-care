# Feature preservation and navigation fix

This version preserves all existing `advanced.html` functionality, including risk curve graph, learning quizzes, inheritance graph/Punnett square, partner matching, informed choices, triage, privacy, pilot, live server and staff workflows. No business logic or tests were removed.

The calm patient homepage now includes a visible **All features** menu and nine feature cards that route directly to the matching existing advanced page using `advanced.html?view=<page>`. The guided patient flow and intro remain.

Do not claim clinical validation: all examples are synthetic and research models are not individual clinical risk estimates. Live backend functions require backend availability.
