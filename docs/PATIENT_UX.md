# Patient experience redesign

The primary navigation now prioritizes Home, Start Here, Understand Results, My Choices, and My Privacy. Research models, staff tools, raw matching controls, and backend diagnostics remain accessible via **More tools**.

## Guided demonstration
The new Start Here view uses fictional scenarios in four steps: choose a scenario, explore individual consent, understand a simplified explanation, and see possible next steps. A refused consent locks the displayed couple-level outcome. The walkthrough is purely front-end and does **not** constitute security or clinical validation; the existing API workflows remain separate.

## Safety notes
No real reports or patient information should be uploaded. No live appointment is booked. No personal clinical interpretation is provided. The content intentionally avoids claiming regulatory approval or partnership with Malaffi/Abu Dhabi health systems.

## Accessibility
Larger touch targets, keyboard focus indicators, responsive single-column cards, plain language, and reduced navigation complexity. Arabic clinical explanations remain available in Detailed matching; the new guided demo is currently English-only and needs full Arabic translation before an Arabic-language patient pilot.
