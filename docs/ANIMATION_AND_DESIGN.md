# Animated website refresh

The original application flows and backend are preserved. The homepage has upgraded responsive layout, typography, hover interactions, animated DNA artwork and a 2.9-second skippable intro. Reduced-motion accessibility preference bypasses the intro.

## Test it

Open `frontend/index.html` directly for the visual preview and synthetic UI mode. To verify real server-side consent gates, run the backend using the existing README instructions. A file-open preview is **not evidence of server-side privacy enforcement**.

## Medical disclaimer

This is an educational research prototype using synthetic data, not a clinically validated or approved diagnostic tool. Independent medical review and clinical validation are future work.
